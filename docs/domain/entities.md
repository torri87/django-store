# Сутності та атрибути

Список ключових сутностей домену інтернет-магазину, згрупований за піддоменами (bounded contexts). Терміни відповідають глосарію (`glossary.md`), а межі контекстів показано на діаграмі (`context_map.png`).

Позначки: **PK** первинний ключ, **FK** посилання на іншу сутність, **unique** унікальне значення. Статус реалізації: **[готово]** є в коді проєкту, **[план]** заплановано.

---

## Контекст Identity (Користувачі) [готово]

### User

Обліковий запис користувача.

| Атрибут | Тип | Опис і обмеження |
|---|---|---|
| `id` | ціле, PK | Ідентифікатор |
| `username` | рядок до 150, unique | Логін |
| `email` | рядок до 255, unique | Електронна пошта |
| `password` | рядок (хеш) | Пароль у вигляді хеша, назовні не повертається |
| `first_name` | рядок до 150 | Ім'я (необов'язково) |
| `last_name` | рядок до 150 | Прізвище (необов'язково) |
| `address` | рядок до 255 | Адреса (необов'язково) |
| `phone` | рядок до 20 | Телефон (необов'язково) |

## Контекст Catalog (Каталог) [готово]

### Category

Група товарів.

| Атрибут | Тип | Опис і обмеження |
|---|---|---|
| `id` | ціле, PK | Ідентифікатор |
| `name` | рядок до 255, unique | Назва категорії |
| `description` | рядок до 255 | Опис (необов'язково) |

### Product

Товар, який можна купити.

| Атрибут | Тип | Опис і обмеження |
|---|---|---|
| `id` | ціле, PK | Ідентифікатор |
| `category` | FK → Category | Категорія, до якої належить товар |
| `name` | рядок до 255 | Назва |
| `description` | текст | Опис (необов'язково) |
| `price` | десяткове (10 цифр, 2 після коми) | Поточна ціна, більша за нуль |
| `stock` | ціле, не менше 0 | Залишок на складі, за замовчуванням 0 |
| `is_active` | так/ні | Чи показується товар у каталозі, за замовчуванням так |
| `time_created` | дата й час | Час створення, проставляється автоматично |

## Контекст Ordering (Замовлення) [готово], ядро домену

### Order

Замовлення покупця.

| Атрибут | Тип | Опис і обмеження |
|---|---|---|
| `id` | ціле, PK | Ідентифікатор (номер замовлення) |
| `user` | FK → User | Покупець, власник замовлення |
| `status` | перелік | `PENDING` (очікує), `PAID` (оплачене), `SHIPPED` (відправлене), `DELIVERED` (доставлене). За замовчуванням `PENDING` |
| `time_created` | дата й час | Час створення, проставляється автоматично |
| `items` | список OrderItem | Позиції замовлення, не менше однієї |
| `total` | десяткове (обчислюване) | Сума замовлення: ціна позицій помножена на кількість |

### OrderItem

Позиція замовлення.

| Атрибут | Тип | Опис і обмеження |
|---|---|---|
| `id` | ціле, PK | Ідентифікатор |
| `order` | FK → Order | Замовлення, до якого належить позиція |
| `product` | FK → Product | Товар |
| `quantity` | ціле, не менше 1 | Кількість |
| `price` | десяткове (10 цифр, 2 після коми) | Ціна одиниці товару, зафіксована на момент замовлення (у доменній моделі `unit_price`) |

Правило: один товар може бути в замовленні лише в одній позиції.

## Контекст Payments (Оплата) [план]

### Payment

Платіж за замовлення.

| Атрибут | Тип | Опис і обмеження |
|---|---|---|
| `id` | ціле, PK | Ідентифікатор |
| `order` | FK → Order | Замовлення, яке оплачується |
| `amount` | десяткове | Сума, дорівнює сумі замовлення |
| `status` | перелік | `PENDING` (очікує), `SUCCEEDED` (успішний), `FAILED` (невдалий) |

---

## Контекст Shipping (Доставка) [план]

### Shipment

Відправлення оплаченого замовлення.

| Атрибут | Тип | Опис і обмеження |
|---|---|---|
| `id` | ціле, PK | Ідентифікатор |
| `order` | FK → Order | Замовлення, яке відправляється |
| `address` | рядок | Адреса доставки |
| `status` | перелік | Статус відправлення |
| `tracking_number` | рядок | Номер відправлення (необов'язково) |

---

## Контекст Notifications (Сповіщення) [план]

### Notification

Повідомлення покупцю.

| Атрибут | Тип | Опис і обмеження |
|---|---|---|
| `id` | ціле, PK | Ідентифікатор |
| `recipient` | FK → User | Одержувач |
| `subject` | рядок | Тема |
| `body` | текст | Текст повідомлення |
| `channel` | перелік | Спосіб доставки (наприклад, email) |

## Зв'язки між сутностями

```
Category 1 ──< Product
User     1 ──< Order
Order    1 ──< OrderItem >── 1 Product
Order    1 ──  Payment      (план)
Order    1 ──  Shipment     (план)
User     1 ──< Notification (план)
```

Знак `<` означає «багато»: одна категорія містить багато товарів, один користувач має багато замовлень, одне замовлення складається з багатьох позицій.
